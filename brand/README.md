# Baskule logo sources

Outlined SVGs of the wordmark and pivot mark, for light (`wordmark.svg`, `mark.svg`) and dark
(`wordmark-inverse.svg`, `mark-inverse.svg`) backgrounds. They need no font. Every shipped logo and icon,
including the GitHub avatar and social preview PNGs, is generated by `app/scripts/export-baskule-assets.ts`.

Read [the brand guide](../docs/branding.md) for usage, colors, generation, and GitHub upload instructions.
