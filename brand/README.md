# Baskule logo sources

Outlined SVGs of the wordmark and the /e mark, for light (`wordmark.svg`, `mark.svg`) and dark
(`wordmark-inverse.svg`, `mark-inverse.svg`) backgrounds. They need no font. Every shipped logo and icon is
generated from them by `app/scripts/export-baskule-assets.ts`.

Read [the brand guide](../docs/branding.md) for usage, colours, tokens and the asset list.
