# Baskule application

This directory contains Baskule's T3 Code clients and server. The [project README](../README.md) describes the self-hosted team platform. [BASKULE.md](BASKULE.md) records the upstream release and the adaptations that remain necessary.

Baskule runs OpenCode 2 as its only agent driver. Vendor models run through OpenCode. Each SpaceCell embeds the runtime, while local and external OpenCode instances retain separate endpoints, credentials and model settings.

Follow the [build guide](../docs/building.md), [development workflow](../docs/development-workflow.md) and [agent instructions](AGENTS.md). The [provider guide](docs/user/providers-opencode.md) describes local OpenCode setup.
