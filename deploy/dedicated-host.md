# Dedicated hosts

Use [Install Baskule](../docs/install.md) for one machine or [Install a cluster](../docs/install-cluster.md) for
separate platform, edge, and computers hosts. Those guides own network configuration, external storage, updates,
backup, and restore. [Build Baskule](../docs/building.md) covers installations built from a checkout.

The optional [runner tools](runner/README.md) are separate from released installations. They require explicit
staging addresses and owner-managed isolation policies. Public contribution builds need disposable workers or
equivalent isolation. Deploying, restarting, or wiping an existing installation requires its owner's authorization.
