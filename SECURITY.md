# Security policy

Security fixes target the latest Baskule release. Upgrade to the latest release before reporting an issue that may already be fixed.

## Report a vulnerability

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** option in the [Baskule security advisories](https://github.com/baskule/baskule/security/advisories). Do not open a public issue or disclose exploit details publicly before coordinating with maintainers.

Include the affected version, installation configuration, steps to reproduce, expected and observed behavior, and potential impact. Provide a minimal proof of concept when possible. Remove credentials, tokens, and personal data from reports and attachments.

Maintainers review reports privately, may ask for more information, and coordinate fixes and disclosure with the reporter through the advisory. Response and fix times depend on severity and the information available.
